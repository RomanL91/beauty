# Итерация 12 (замысел, не ТЗ) — интервью об услуге и привычки мастера

Записано по обсуждению с владельцем 2026-10-20. Полное ТЗ — когда возьмём в работу.

## Зачем

Опыт мастера — в правилах записи. Примеры из жизни:

* **Наталья, парикмахер.** Стрижка — 40 минут, сложное окрашивание — до 3 часов. Сложное
  берёт с утра, простые стрижки — под конец дня. Два окрашивания за день — предел, после
  них другую работу не берёт.
* **Елена, косметолог.** Ботокс — только по пятницам. Вскрытой ампулы хватает на несколько
  клиентов, срок годности после вскрытия короткий — клиентов набирают «под ампулу».

## Решение: агент сам расспрашивает мастера

* Мастер добавил услугу → в «Поручениях» (и push) агент начинает короткое интервью:
  3–5 вопросов, варианты кнопками (карточки выбора), можно голосом; пропустить и
  продолжить позже. Что спросить — агент знает из общих знаний модели о процедуре
  (ботокс → «ампула на несколько клиентов? в какие дни?»).
* Итог — карточка «Поняла так: …» → мастер «Сохранить» / «Поправить». Сохраняется в
  систему (не в память Hermes — её не видит ресепшн):
  * описание для клиентов (черновик, мастер подтверждает);
  * нюансы для консультаций (противопоказания, подготовка, уход) — в инструкциях ресепшна;
  * правила записи — строгие, их соблюдает код (поиск окон и сама запись).
* Интервью-знакомство с мастером (при подключении или по второй «долгой» услуге) — привычки
  дня: «как вы любите строить день?».
* Уже созданные услуги: агент предлагает расспросить по услугам без описания; поручение
  «расскажи агенту про услугу».

## Правила под капотом (мастер видит их в настройках, но заводит через интервью)

* Услуга: дни недели; окно начала («не позже 12:00»); максимум в день; партия — мин./макс.
  клиентов в день, записи подряд в окне (ампула); длительность «от–до» по уточнению.
* День: пометка «тяжёлая», лимит тяжёлых в день, «после лимита день закрыт».
* Мягкие привычки («сложное — утром») — текстом в инструкциях; агент сначала предлагает
  подходящие окна. Строго — только по слову мастера.
* Партия не набирается (к четвергу 1 из 4) — агент спрашивает мастера карточкой: перенести
  или вскрывать. Лист ожидания на следующую партию.
* Строгие правила проверяются и в поиске окон, и при записи (гонка за последнее место).

## Вне итерации

* Веб-поиск об услуге (у агента кабинета тулсет `web` выключен намеренно; нужен ключ
  поискового провайдера) — потом, только для кабинета.
* Сам пишет клиентам «пора повторить» (по истории визитов) — отдельно, аккуратно со спамом.
* Агент предлагает правила по наблюдениям («трижды отклонили стрижки после 18:00»).

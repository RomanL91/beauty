# Макеты PWA — клиент и мастер

Источник: канвас «Beauty — макеты PWA» (claude.ai, Design), выгружен 2026-10-15.
Файлы `*.dc.html` — исходники артбордов канваса; вне канваса они не рендерятся
(нужен его `support.js`). Переносим визуал и тексты, **не код**.

| Файл | Экран | Приложение | Маршрут |
|---|---|---|---|
| `Main.dc.html` | Страница мастера | client | `/` |
| `ClientLogin.dc.html` | Вход через Telegram | client | `/login?return=…` |
| `ClientChat.dc.html` | Чат с администратором | client | `/chat` |
| `MasterSchedule.dc.html` | График дня | master | `/schedule/:date?` |
| `MasterChats.dc.html` | Все чаты | master | `/chats?filter=…&q=…` |
| `MasterDialog.dc.html` | Диалог и пульт агента | master | `/chats/:id` |
| `MasterAssistant.dc.html` | Поручение голосом | master | `/assistant` |

Клиентское приложение живёт на поддомене мастера (`alisa.beautiful.kz`), мастер —
на `master.beautiful.kz`. Ширина макетов — 390 px (iPhone 14/15).

### Типографика

- **Unbounded** 500/600 — заголовки: код входа 64/72, h1 входа 24/30, имя мастера 22/28,
  h1 экранов мастера 20/26, заголовок «Поручения» 17, h2 секций 16.
- **Manrope** 400/500/600/700 — всё остальное: 16 (кнопки, имена), 15/21–23 (тело, пузыри),
  14/20, 13/19 (подписи), 12 (метки, время), 11 (подписи нижней навигации).
- Метки-капсом: 12–13 px, 700, `letter-spacing: .06–.08em`, uppercase.

### Радиусы и размеры

- Радиусы: 8 (бейджи в списке), 12 (чипы слотов, малые кнопки), 14 (плашки, поиск, дни
  недели), 16 (основные кнопки, карточки графика), 18 (пузыри, списки, карточки),
  22 (карточка кода), полный (круглые кнопки, фильтры).
- Хвост пузыря: свой — `18 18 4 18`, собеседник — `18 18 18 4`.
- Зона нажатия ≥ 44 px; основные CTA 52–54 px; пункты навигации 52 px; FAB «Поручить» 56 px;
  кнопка голосового поручения 64 px.
- Поля экрана: 20 px (клиент, график), 12–16 px (чаты, шапки диалогов).

### Иконки

Инлайн SVG, stroke 1.8–2, `stroke-linecap/linejoin: round`, 14–24 px, `aria-hidden` у
декоративных, `aria-label` у кнопок-иконок.

## Решения, зафиксированные в макетах

- Клиенту отвечает **администратор-ИИ**; ответы ИИ подписаны «Ответ ИИ · время», у ответов
  по базе знаний — блок «Источники».
- Запись — **заявка с удержанием слота**: «Ждёт подтверждения», «Время держим за вами»,
  «Алиса ответит до HH:MM, иначе пришлём новые варианты». У мастера — обратный отсчёт
  «автоотклонение через …».
- Вход — через Telegram-бота по **двузначному коду** с таймером; предупреждение «если бот
  показывает другие цифры — не нажимайте».
- Диалог у мастера: переключатель **«Агент / Я»**; в режиме «Я» агент на паузе. Сообщение
  мастера клиент видит с подписью «Алиса», **без пометки ИИ**.
- **Заметка агента** — пунктирная карточка «видите только вы», клиенту не уходит.
- Голосовые клиента мастер видит **расшифровкой** («Голосовое 0:07 · расшифровка»).
- Поручения: голос (удержание большой кнопки) или текст; агент уточняет **карточками выбора**
  и показывает **прогресс шагов** (готово / ждём / предстоит).
- Нижняя навигация мастера: График · Чаты (счётчик) · FAB «Поручить» · Клиенты · Настройки.
  «Клиенты» и «Настройки» — вне итерации 1 (заглушки).
- Плейсхолдеры в квадратных скобках (`[цена]`, `[N]`, `[адрес кабинета]`, `[фото]`) — данные
  из API, в макете не заданы.
